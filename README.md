# Real Estate Analysis with Machine Learning

This repository focuses on creating a machine learning project that analyzes real estate listings through several key steps:

1. **Web Scraping**: Automatically collecting real estate listings data from various sources
2. **Data Processing**: Cleaning and transforming the raw data into a structured format
3. **Database Integration**: Storing the processed data in a database for efficient querying
4. **Machine Learning Analysis**: Applying ML models to extract insights and predictions from the collected data

## Project Goals

- Create robust web scraping tools for real estate listings
- Build a reliable data pipeline for processing and storing property information
- Develop ML models that can analyze pricing trends, property valuations, and market patterns
- Generate actionable insights for real estate investment decisions

## Technologies

- **Web Scraping**: playwright
- **Data Processing**: Pandas, NumPy
- **Database**: PostgreSQL, MongoDB
- **Machine Learning**: Scikit-learn, TensorFlow, PyTorch
